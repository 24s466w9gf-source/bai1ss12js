Lỗi logic nằm ở dòng điều kiện if (sub.daysOverdue >= 3). Toán tử >= (lớn hơn hoặc bằng) sẽ bao gồm cả giá trị 3. Do đó, khi khách hàng nợ cước đúng 3 ngày, biểu thức này trả về true, khiến hệ thống lập tức thực thi khối lệnh hạ cấp gói cước xuống FREE thay vì chuyển sang trạng thái GRACE_PERIOD.
